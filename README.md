## 🌟 About The Project

**Family Hub** is a premium family productivity dashboard created to bring everyday family activities into one beautiful and easy-to-use digital space.

Whether you want to manage household chores, plan important events, track shared tasks or create family rewards, Family Hub helps everyone stay connected and organized.

The project focuses on:

- 🎨 Modern visual design
- 📱 Mobile-first responsiveness
- ✨ Smooth animations
- 🧭 Simple navigation
- 💾 Persistent browser storage
- 🌙 Light and dark themes
- ♿ Reduced-motion accessibility support
- ⚡ Fast performance without heavy frameworks

### Accessibility-friendly motion

Family Hub respects the user's device motion preference through:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
